---
name: clodey-status
description: Use when asked about token usage, how many tokens are left, or how Clodey is doing. Show Clodey mascot status — current token usage, session state, and reset timer.
---

Run: node ~/.claude/plugins/clodey/scripts/clodey.js status

This prints a summary of:
- Current token usage percentage and estimated remaining
- Active session state
- Time until limit resets
- Which animation state Clodey is currently showing
